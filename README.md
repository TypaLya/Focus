# Focus — менеджер задач и проектов

Focus — одностраничное веб-приложение для личного планирования. Интерфейс и логика приложения находятся в одном файле `index.html`; внешние библиотеки, сборка и сервер не требуются.

## Возможности

- Создание, редактирование, выполнение и удаление обычных задач.
- Создание проектов (глобальных задач) с несколькими этапами / подзадачами.
- Отображение прогресса выполнения проектов и общей статистики.
- Категории, приоритеты и сроки выполнения.
- Просмотр задач и проектов, поиск и фильтрация.
- Экспорт резервной копии и восстановление данных из файла.
- Сохранение данных в `localStorage` браузера.
- Адаптивный интерфейс для компьютеров и мобильных устройств.

## Запуск локально

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в современном браузере.

Локальный веб-сервер для запуска не обязателен.

## Публикация через GitHub Pages

1. Откройте настройки репозитория на GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/(root)`, затем нажмите **Save**.
5. После публикации GitHub Pages покажет адрес сайта в этом же разделе.

## Хранение данных

Задачи хранятся локально в `localStorage` браузера. Они сохраняются при обновлении страницы, но не синхронизируются между разными браузерами или устройствами. Для такой синхронизации потребуется серверная часть и общая база данных.
